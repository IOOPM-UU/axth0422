# Inlupp 2

## Running the program

1. If the last compilation was for the tests, run `make clean` in the terminal.
1. To compile and run the program, run `make all` in the terminal.
1. Follow the instructions in the terminal on how to use the program.

## Running the tests

1. If the last compilation was for the program, run `make clean` in the terminal.
1. To compile and run the tests, run `make test` in the terminal.
